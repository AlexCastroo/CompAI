# CompAI

**AI-powered software engineering assistant built with Python.**

CompAI is an experimental project focused on building a modular software engineering assistant capable of understanding repositories, supporting development workflows and integrating AI capabilities.

## Goals

- Learn and apply AI engineering principles.
- Build a modular and extensible Python architecture.
- Understand and analyze software repositories.
- Integrate different LLM providers and execution engines.
- Develop specialized agents and engineering workflows.

## Current Status

**Phase:** P0 — Foundations

**First milestone:** Build a modular Python CLI capable of identifying and inspecting software repositories.

## Tech Stack

- Python
- uv
- Typer
- pytest
- Ruff
- Git

## Philosophy

Learn by building. Prioritize understanding, simplicity and incremental development over premature complexity.
